# Enclosure

This directory is for 3D printable enclosure files.

## Planned Files

- `enclosure.stl` - Main body
- `lid.stl` - Cover with display cutout

## Design Requirements

- Display window: 30mm x 12mm (approximate visible area)
- Access for USB-C port
- Slot for power switch
- Battery compartment (optional)

## Contributing

If you design an enclosure, please submit a pull request with:
- STL files
- Source files (Fusion 360, OpenSCAD, etc.)
- Assembly notes
