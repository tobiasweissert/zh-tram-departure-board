# Enclosure

This directory contains the ZH Tram Departure Board enclosure files.

## Files

- [zh-tram-departure-board.stl](zh-tram-departure-board.stl) - Printable enclosure
- [zh-tram-departure-board.f3d](zh-tram-departure-board.f3d) - Fusion 360 source

## Design Requirements

- Display window: 30mm x 12mm (approximate visible area)
- Access for USB-C port
- Slot for power switch
- Battery compartment (optional)

## Contributing

If you design an enclosure, please submit a pull request with:
- STL files
- Source files (Fusion 360, OpenSCAD, etc.)
- Assembly notes
